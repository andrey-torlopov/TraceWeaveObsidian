# Возможности и файлы

*[English](../en/features.md)*

## Исследование над обычным Markdown

Создавайте отдельные исследования с одним графом в каждом. Каждый узел связан с обычным Markdown-файлом этого vault. В **+ Документ** задайте название узла и выберите существующую заметку без копирования либо создайте новую согласно настройке папки новых заметок Obsidian. Название в графе может отличаться от имени файла. Текст и Properties остаются в самой заметке; метаданные, отношения и пути хранятся отдельно.

Двойное нажатие на узел открывает заметку в Obsidian. **Читать** явно раскрывает карточку. Досье доступно списком и карточками; открытие заметки не создаёт её внутреннюю копию в плагине.

Метаданные документа включают тип, отдельный эмодзи карточки, оценку, уверенность, типизированные атрибуты и источники. Атрибуты поддерживают текст, число, логическое значение, дату, дату/время, URL и координаты. Источник может ссылаться на документ, зарегистрированный файл или явный URL и содержать цитату, локатор и комментарий.

Ищите по исследованию, фильтруйте по типу, оценке и группе. Переименование заметки через Obsidian обновляет её централизованную привязку. **Диагностика проекта** проверяет пути заметок и хеши зарегистрированных оригиналов, показывает отсутствующие, изменённые и недопустимые файлы и выделяет затронутые узлы красным. Файлы, упомянутые только в Markdown, не относятся к этой проверке зарегистрированных материалов.

Если при открытии привязанная заметка отсутствует, выберите другой файл хранилища либо создайте новую с названием узла. ID, атрибуты и связи узла сохранятся; создание новой заметки не восстанавливает прежний удалённый текст. Явная перепривязка также доступна в **Метаданные → Привязка заметки**. Недоступный оригинал восстановите из backup и повторите диагностику; изменённые байты не принимаются автоматически.

## Связи и группы

Между двумя документами может быть несколько связей с подписью, направлением, оценкой, уверенностью, заметкой и источниками. Новые отношения имеют один тип «связано с». На графе видна только заданная пользователем подпись; исторические типы сохраняются для переноса. Гипотеза отображается пунктиром.

При масштабе ниже 0.58 карточки становятся кругами; приближение возвращает раскрытое состояние. Одноуровневые группы сворачиваются и проецируют связи участников без изменения исходных концов отношений. Undo/redo применяется к операциям с метаданными; текст заметки использует историю штатного редактора Obsidian. Корзина сохраняет файлы и позволяет восстановить пакет удаления.

## Любой файл как материал

Импортируйте явно выбранные файлы, в том числе за пределами vault: плагин копирует их в `TWData/projects/<постоянная папка исследования>/`, разделяя на `images`, `video`, `audio`, `documents`, `archives` и `other`. **Настройки → TraceWeave → Папка данных** меняет видимый корень `TWData`. Папка исследования сохраняет имя после переименования графа; совпадающие названия получают номер. Имя файла содержит читаемую часть исходного имени и уникальный идентификатор.

Оригиналы — неизменяемые управляемые копии с SHA-256; один материал может иметь независимые привязки к документам. Отсоединение одной привязки не удаляет оригинал. Размер файла — до **512 MiB**. Новые заметки узлов используют обычную папку новых заметок Obsidian, а не каталог вложений.

| Материал | Доступное действие |
|---|---|
| PNG, JPEG, WebP, GIF | Локальный preview после проверки сигнатуры и размера |
| Аудио и видео | Локальный плеер без autoplay, если движок Obsidian поддерживает контейнер и кодек |
| PDF | Открытие видимого оригинала штатным viewer Obsidian |
| Архивы, файлы без расширения, другие бинарные файлы | Каталог и сохранение; показ в системном файловом менеджере |
| HTML, SVG, неизвестные форматы | Хранение без исполнения активного содержимого |

**Материалы → Проверить оригиналы** выявляет отсутствующие или изменённые файлы. Каталог плагина показывает любые форматы независимо от настройки Obsidian **Show all file types**. Включите её отдельно, если хотите видеть такие файлы и в штатном проводнике.

## Ссылки и снимки

Wikilinks, локальные Markdown-ссылки и встраивания разрешаются относительно пути исходной заметки. Допустимые изображения и медиа получают preview; встраивание заметки ведёт в штатный редактор вместо рекурсивного чтения всего vault. Удалённые изображения автоматически не загружаются. Одна текстовая ссылка не регистрирует файл в библиотеке материалов и не добавляет его в backup ZIP или внутренний снимок. **Экспорт отчёта** дополнительно копирует разрешённые локальные ссылки на файлы в отдельную читаемую папку.

Снимок отчёта фиксирует явный набор документов, отношения между ними и зарегистрированные привязанные материалы. Новые снимки находятся в `exports/<постоянная папка исследования>/snapshots/` внутри настроенной папки данных; исторические остаются на прежних местах. Последующие правки не меняют снимок. Представление плагина открывает его только для чтения; сверх **16 MiB preview** полный файл остаётся на диске и доступен через файловый менеджер. PDF и прочие захваченные файлы снимка также показываются там; видимые исходные PDF открываются штатно.
