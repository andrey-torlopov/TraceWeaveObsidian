# Быстрый старт

*[English](../en/quick-start.md)*

[Установите и включите TraceWeave](installation.md). Ниже приведены точные подписи текущего интерфейса.

## Начните со своих заметок

1. В палитре команд выполните **TraceWeave: Открыть исследование**.
2. Нажмите **Создать исследование**, задайте название и сохраните.
3. Выберите **Подключить заметку из vault** и Markdown-файл из любой обычной папки этого vault. Файл останется на месте. Также можно нажать правой кнопкой на заметку в проводнике Obsidian → **Подключить к TraceWeave** либо выполнить **TraceWeave: Подключить текущую заметку к исследованию** для открытого файла.
4. Нажмите **+ Документ**, чтобы создать новый документ. Его Markdown-файл появится в `Исследования/Заметки/`.
5. Выберите карточку и нажмите **Открыть заметку** для правки текста штатным редактором Obsidian. **Метаданные** изменяет название в графе, тип, оценку, атрибуты и источники.

Граф содержит только явно подключённые документы. `[[Wikilink]]` в тексте заметки не создаёт предметную связь автоматически.

## Соедините и сгруппируйте

Перетащите соединитель между карточками либо нажмите **+ Связь** в инспекторе документа. При необходимости задайте подпись, направление и оценку, затем сохраните. Новая связь означает «связано с»; отдельного выбора типа нет. **Гипотеза** показывает пунктир, остальные оценки — сплошную линию.

Отдалите граф для круглых узлов, приблизьте для карточек. **Читать** раскрывает карточку, **Показать всё** подбирает масштаб всего графа. Shift+клик выделяет несколько карточек; затем нажмите **Сгруппировать**. Группировка одноуровневая; сворачивание не меняет исходные концы отношений.

Перейдите в **Досье** для списка или карточек, в **Материалы** для каталога файлов, в **Корзина** для восстановления пакета удаления. Удаление из графа сохраняет Markdown и оригиналы файлов.

## Добавьте файлы и сохраните работу

В инспекторе нажмите **Добавить файлы**, чтобы импортировать и прикрепить выбранные материалы. **Из библиотеки** подключает уже зарегистрированный материал. Изображения, аудио и видео получают preview, если формат поддерживается; PDF и произвольные файлы доступны и без встроенного просмотра.

**Отчёт** фиксирует снимок только для чтения; **Снимки** открывает существующие. **Копия vault ZIP** создаёт переносимую копию текущего исследования; сохраните ZIP также вне vault. Несмотря на название кнопки, это не копия всего хранилища. Перед использованием прочитайте [состав backup и ограничения импорта](backup-import.md).
