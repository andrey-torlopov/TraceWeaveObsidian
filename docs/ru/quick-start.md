# Быстрый старт

*[English](../en/quick-start.md)*

[Установите и включите TraceWeave](installation.md). Ниже приведены подписи интерфейса **0.2.0**. Язык следует настройке Obsidian; отдельно выбрать русский или английский можно в **Настройки → TraceWeave → Язык интерфейса**.

## Начните со своих заметок

1. В палитре команд выполните **TraceWeave: Открыть исследование**.
2. Нажмите **Создать исследование**, задайте название и сохраните.
3. Нажмите **+ Документ**, задайте название узла и выберите **Выбрать заметку из хранилища**. Подключите Markdown-файл из обычной папки этого vault. Текст, Properties, имя и расположение файла не меняются; название в графе может отличаться от имени файла.
4. Для новой заметки выберите в этом же диалоге **Создать новую заметку**. Её папку определяет настройка новых заметок Obsidian. Существующий файл не заменяется; при совпадении имён добавляется номер.
5. Дважды нажмите на узел либо выберите **Открыть заметку**, чтобы открыть привязанный файл в редакторе Obsidian. **Метаданные** изменяет название в графе, тип, оценку, атрибуты и источники.

Также доступны правый клик по заметке в проводнике Obsidian → **Подключить к TraceWeave** и команда **TraceWeave: Подключить текущую заметку к исследованию**. Эти способы используют имя файла как начальное название узла.

Граф содержит только явно подключённые документы. `[[Wikilink]]` в тексте заметки не создаёт предметную связь автоматически.

## Соедините и сгруппируйте

Перетащите соединитель между карточками либо нажмите **+ Связь** в инспекторе документа. При необходимости задайте подпись, направление и оценку, затем сохраните. Новая связь означает «связано с»; отдельного выбора типа нет. **Гипотеза** показывает пунктир, остальные оценки — сплошную линию.

Отдалите граф для круглых узлов, приблизьте для карточек. **Читать** раскрывает карточку; двойное нажатие открывает заметку вместо раскрытия. **Показать всё** подбирает масштаб всего графа. Shift+клик выделяет несколько карточек; затем нажмите **Сгруппировать**. Группировка одноуровневая; сворачивание не меняет исходные концы отношений.

Перейдите в **Досье** для списка или карточек, в **Материалы** для каталога файлов, в **Корзина** для восстановления пакета удаления. Удаление из графа сохраняет Markdown и оригиналы файлов.

## Добавьте файлы и сохраните работу

В инспекторе нажмите **Добавить файлы**, чтобы импортировать и прикрепить выбранные материалы. **Из библиотеки** подключает уже зарегистрированный материал. Изображения, аудио и видео получают preview, если формат поддерживается; PDF и произвольные файлы доступны и без встроенного просмотра.

Видимая папка данных по умолчанию — `TWData`. Вложения разделены по типам в `TWData/projects/<постоянная папка исследования>/`, отчёты и ZIP находятся в `TWData/exports/`. Корень меняется в **Настройки → TraceWeave → Папка данных**. Эта настройка не задаёт папку заметок узлов.

**Экспорт отчёта** создаёт `summary.md` и `scheme.canvas` для чтения на телефоне. **Снимок отчёта** фиксирует неизменяемый результат, **Снимки** открывает сохранённые результаты. **Копия vault ZIP** создаёт переносимую копию выбранного исследования; сохраните ZIP также вне vault. Несмотря на название кнопки, это не копия всего хранилища. Прочитайте [состав backup и ограничения импорта](backup-import.md).

## Проверьте заметки и файлы

Нажмите **Диагностика проекта** рядом с импортом и экспортом. Проверяются привязанные заметки и контрольные суммы зарегистрированных файлов. Отсутствующие, изменённые и недопустимые файлы показаны с путями; затронутые узлы графа и досье становятся красными.

При открытии отсутствующей заметки можно выбрать другой файл из хранилища либо создать новую заметку. Новая использует название узла и обычную папку Obsidian; ID, атрибуты и связи узла сохраняются. Оригиналы файлов восстановите из резервной копии и запустите диагностику снова. Изменённые байты оригинала не принимаются автоматически.
