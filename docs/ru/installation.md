# Установка и обновления

*[English](../en/installation.md)*

## Требования

Настольный Obsidian **1.14.4 или новее**, локальный vault с доступом на запись. Мобильная версия не поддерживается. Плагин использует файловые API Node.js/Electron из Obsidian; отдельно устанавливать Node.js, Docker или базу данных не нужно.

Нативные проверки проводились на macOS с Obsidian 1.14.4. Windows, Linux, все медиакодеки и производительность больших хранилищ полностью не проверены. Начните с тестового vault; ценные материалы храните с полной резервной копией.

## Как найти TraceWeave в Obsidian

**Публикация в каталоге Community plugins ещё ожидается. Один релиз GitHub не делает плагин доступным в поиске Obsidian.** После одобрения и публикации каталога:

1. Откройте **Настройки → Сторонние плагины** и при необходимости разрешите их использование.
2. Нажмите **Обзор**, найдите **TraceWeave** и откройте его страницу.
3. Нажмите **Установить**, затем **Включить**.
4. В палитре команд выполните **TraceWeave: Открыть исследование**.

[Официальный порядок публикации и обновлений](https://docs.obsidian.md/Plugins/Releasing/Submit%20your%20plugin). До одобрения используйте опубликованный релиз через BRAT либо ручной способ ниже.

## Установка через BRAT

[BRAT](https://github.com/TfTHacker/obsidian42-brat) — необязательный сторонний плагин для установки и обновления плагинов из релизов GitHub.

1. В **Настройки → Сторонние плагины → Обзор** найдите **BRAT**, установите и включите его.
2. В настройках BRAT выберите **Add Beta plugin**.
3. Укажите репозиторий `andrey-torlopov/TraceWeaveObsidian` и добавьте плагин из опубликованного релиза.
4. Включите **TraceWeave** в списке сторонних плагинов, если он не включился автоматически.
5. Полностью перезапустите Obsidian с этим vault и выполните **TraceWeave: Открыть исследование**.

BRAT нужен релиз с `main.js`, `manifest.json` и `styles.css`. Пустого репозитория или автоматического GitHub Source code ZIP недостаточно. Если интерфейс BRAT изменился, следуйте документации по ссылке выше.

## Ручной запасной способ

1. Откройте [GitHub Releases](https://github.com/andrey-torlopov/TraceWeaveObsidian/releases), скачайте установочный `traceweave-0.1.3.zip` либо три собранных файла отдельно.
2. Создайте в vault папку `.obsidian/plugins/traceweave/`.
3. Положите `main.js`, `manifest.json`, `styles.css` непосредственно в неё. Не должно быть дополнительной вложенности `traceweave/traceweave/`.
4. Откройте Obsidian, включите TraceWeave в сторонних плагинах и перезапустите приложение с этим vault.

Исходники, `node_modules` и данные исследования в папку плагина копировать не нужно.

## Обновление и удаление

Сохраните правки, остановите запись с других устройств и перед обновлением сделайте файловую копию закрытого vault со скрытой `.twdata/`. Обновите плагин выбранным способом; при ручном способе замените три собранных файла. **После обновления полностью перезапустите Obsidian.** Одного выключения и включения плагина недостаточно для проверенного сценария загрузки.

Обновление с 0.1.0/0.1.1 переносит служебные данные в `.twdata/`, управляемые заметки и файлы — в видимые папки `Исследования/`. Подключённые заметки в других папках остаются на месте. Миграцию выполняет плагин: не переименовывайте старые папки и не удаляйте её маркер. Подробности — в [протоколе хранения](../storage.md). Возврат к старому расположению требует восстановления полной копии vault до обновления.

После выключения или удаления плагина заметки, оригиналы и `.twdata/` остаются на диске. Сохраните `.twdata/`: восстановить предметные связи и атрибуты из одного Markdown невозможно.
